Bold sans fonts used to render stamp templates (recognition) and synthetic
stamps (eval). Bundled so recognition behaves identically on every machine
(the accuracy thresholds in tests/test_regression.py were measured with
exactly these five). Free licenses: DejaVu (Bitstream Vera license),
Liberation (SIL OFL 1.1), GNU FreeFont (GPL with font exception),
