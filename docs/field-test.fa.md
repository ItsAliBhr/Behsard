# دستورالعمل آزمایش در محل (پایلوت بهسرد)

هدف این آزمایش: نصب ۲ دوربین روی یک نقاله، بررسی کیفیت تصویر، اجرای ۱۵ دقیقه «حالت آزمایش» با مهرهای مشخص، ضبط ۲ دقیقه ویدیوی خام از هر دوربین و ارسال داده‌ها برای تنظیم سیستم.

زمان لازم: حدود ۲ ساعت · افراد: ۱ نفر برای راه‌اندازی + سرکارگر خط.

## ۱. وسایل لازم

| وسیله | تعداد | توضیح |
|---|---|---|
| دوربین Hikvision DS-2CD1063G2-LIU | ۲ | یکی برای هر سمت نقاله |
| پایه یا براکت ثابت | ۲ | لرزش نداشته باشد |
| نور LED بدون سوسو (flicker-free) | ۲ | ترجیحاً با پخش‌کننده (دیفیوزر) |
| سوئیچ PoE یا آداپتور برق ۱۲ ولت | ۱ | |
| کابل شبکه Cat6 | ۳ | |
| لپ‌تاپ ویندوز ۱۰/۱۱ (Core i5، بدون نیاز به اینترنت) | ۱ | با پوشه برنامه بهسرد |
| چند کارتن خالی و مهرهای آزمایشی (مثلاً A12، B07، C15) | — | برای آزمایش |
| متر | ۱ | |

## ۲. نصب دوربین

1. محل نصب: روی **بخش صاف غلتکی** نقاله، جایی که کارتن‌ها بدون چرخش عبور می‌کنند.
2. **فاصله ۴۵ سانتی‌متر** از دوربین تا سطح کارتن (با متر اندازه بگیرید).
3. دوربین **کاملاً روبه‌روی** صفحه کارتن (عمود بر آن)، نه از بالا و نه مایل. ارتفاع دوربین: وسط ارتفاع کارتن.
4. یک دوربین برای سمت چپ و یکی برای سمت راست، **روبه‌روی هم** در یک نقطه از نقاله.
5. نور: هر چراغ LED کمی بالاتر یا کنار دوربین، با زاویه حدود ۳۰ تا ۴۵ درجه نسبت به صفحه کارتن تا بازتاب مستقیم به لنز نیفتد. نور محیط و نور پنجره نباید مستقیم روی کارتن بتابد.
6. پایه‌ها را محکم کنید؛ با عبور کارتن نباید دوربین بلرزد.

## ۳. اتصال لپ‌تاپ و شبکه

1. دوربین‌ها و لپ‌تاپ را به سوئیچ وصل کنید.
2. IP ثابت لپ‌تاپ: `192.168.1.100`، ماسک `255.255.255.0` (تنظیمات کارت شبکه ← IPv4).
3. IP پیش‌فرض دوربین‌های هایک‌ویژن معمولاً `192.168.1.64` است. با نرم‌افزار SADP یا مرورگر، به دوربین اول IP `192.168.1.101` و به دوربین دوم `192.168.1.102` بدهید.
4. در مرورگر آدرس `http://192.168.1.101` را باز کنید و وارد صفحه تنظیمات دوربین شوید.

## ۴. تنظیمات صفحه وب دوربین

برای **هر دو** دوربین:

| بخش | تنظیم |
|---|---|
| Image ← Day/Night Switch | **Day** (همیشه رنگی) |
| Image ← Exposure | **Manual**، زمان نوردهی (Shutter) **۱/۱۰۰۰** ثانیه |
| Image ← Gain | تا جایی که تصویر کافی روشن باشد (هرچه کمتر بهتر) |
| Image ← WDR | **خاموش (OFF)** |
| Image ← Anti-flicker | **خاموش** (نور LED بدون سوسو داریم) |
| Image ← Smart/Supplement Light (IR/White light) | **خاموش** |
| Image ← OSD (تاریخ و نام روی تصویر) | **خاموش** |
| Video ← Main Stream | کدک **H.264**، وضوح **3200×1800**، **CBR**، بیت‌ریت حداکثر (مثلاً 8192 Kbps)، **۱۰ تا ۱۲ فریم بر ثانیه**، I-Frame Interval = ۱۰ |
| Network ← RTSP | فعال، پورت ۵۵۴ |

پس از تغییرات «Save» بزنید.

## ۵. راه‌اندازی برنامه و دستیار دوربین

1. `Behsard.exe` را اجرا کنید؛ مرورگر صفحه داشبورد را باز می‌کند.
2. **دوربین‌ها ← افزودن دوربین**:
   - شناسه: `cam1L` (برای دوربین سمت چپ) و `cam1R` (سمت راست)
   - نقاله: نقاله ۱ · سمت: چپ/راست
   - نوع منبع: دوربین هایک‌ویژن · IP: `192.168.1.101` / `192.168.1.102` · نام کاربری و رمز دوربین · کانال: 101
3. **آزمایش اتصال و گرفتن عکس** را بزنید. همه بررسی‌ها باید «قبول» باشند:
   - **وضوح تصویر:** اگر رد شد، فوکوس/فاصله را اصلاح کنید.
   - **روشنایی:** اگر تاریک است نور اضافه کنید یا Gain را کمی بالا ببرید؛ اگر بیش از حد روشن است شدت نور را کم کنید.
   - **ارتفاع حروف مهر:** یک کارتن مهرخورده را جلوی دوربین نگه دارید و دوباره «آزمایش اتصال» بزنید. باید حداقل **۳۰ پیکسل** باشد؛ اگر کمتر بود دوربین را نزدیک‌تر کنید.
4. **ناحیه دید:** روی عکس با ماوس کادری بکشید که فقط **صفحه کارتن‌های در حال عبور** را بپوشاند (بدون سقف، زمین و پس‌زمینه). «ذخیره ناحیه دید».
5. **تاری حرکت:** چند کارتن را با سرعت عادی نقاله عبور دهید و «بررسی تاری حرکت» را بزنید. باید «قبول» باشد؛ در غیر این صورت زمان نوردهی را کوتاه‌تر و نور را بیشتر کنید.
6. در **داشبورد** باید تصویر زنده هر دو دوربین، خط قرمز شمارش و هنگام عبور کارتن، خطوط سبز لبه کارتن را ببینید.

## ۶. آزمایش ۱۵ دقیقه‌ای در حالت آزمایش

1. صفحه **حالت آزمایش**: مهرهای آزمایشی را وارد کنید (مثلاً `A12 B07 C15`)، «روشن» را بزنید و ذخیره کنید.
2. کارگران (یا خودتان) کارتن‌ها را مثل کار عادی پر/مهر کنند و روی نقاله بگذارند. ترکیبی بسازید:
   - کارتن با مهر سمت چپ، کارتن با مهر سمت راست
   - مهر کم‌رنگ، مهر کج یا وارونه، مهر نیمه
   - چند کارتن **بدون مهر**
   - کارتن‌های چسبیده به هم و توقف و حرکت نقاله
3. در صفحه حالت آزمایش، برای **هر کارتن**: اگر حدس سیستم درست است **Enter**؛ اگر غلط است کلید عدد مهر درست یا تایپ کد و Enter؛ کارتن بدون مهر **0**؛ تشخیص اشتباه (کارتن نبود) **.**
4. حداقل **۱۵ دقیقه** ادامه دهید (هدف: ۱۵۰ کارتن یا بیشتر).
5. جدول «دقت در حالت آزمایش» را یادداشت کنید (عکس صفحه بگیرید).
6. در پایان حالت آزمایش را **خاموش** کنید.

## ۷. ضبط ویدیوی خام

1. صفحه **دوربین‌ها**: برای هر دوربین «شروع ضبط» را بزنید.
2. **۲ دقیقه** کار عادی خط (با توقف و حرکت) را ضبط کنید.
3. «توقف ضبط» را بزنید. فایل‌ها در `data\recordings\cam1L` و `data\recordings\cam1R` هستند.

## ۸. ارسال داده‌ها

1. پوشه‌های زیر را در یک فایل zip قرار دهید:
   - `data\recordings` (ویدیوهای خام)
   - `data\media` (تصاویر کارتن‌ها و برش مهرها)
   - `data\behsard.sqlite` (پایگاه داده شامل تأییدهای حالت آزمایش)
   - `data\logs` (گزارش خطا)
   - `config\behsard.yaml` (**قبل از ارسال، رمز دوربین را از این فایل پاک کنید**)
2. عکس صفحه‌های «حالت آزمایش» و «تنظیم دوربین» (نتیجه بررسی کیفیت) را هم اضافه کنید.
3. فایل را برای تیم تنظیم ارسال کنید.

## ۹. عیب‌یابی

| مشکل | علت احتمالی | راه‌حل |
|---|---|---|
| **تصویر نمی‌آید** («اتصال برقرار نشد») | کابل، IP، رمز، RTSP خاموش | چراغ شبکه دوربین؛ `ping 192.168.1.101` در cmd؛ IP لپ‌تاپ `192.168.1.100`؛ نام کاربری/رمز؛ RTSP فعال و پورت ۵۵۴؛ فایروال ویندوز برای Behsard اجازه دهید. |
| **تصویر تار است** | فوکوس، فاصله، لرزش | فاصله ۴۵ سانتی‌متر را دوباره اندازه بگیرید؛ پایه را محکم کنید؛ لنز را تمیز کنید. |
| **تصویر در حرکت تار است** | نوردهی طولانی | Shutter = ۱/۱۰۰۰ (یا کوتاه‌تر) و نور بیشتر؛ WDR خاموش. |
| **تصویر تاریک است** | نور کم | نور LED اضافه کنید؛ Gain را کمی بالا ببرید. |
| **رنگ‌ها عوض می‌شوند / سیاه‌وسفید است** | حالت شب | Day/Night روی **Day**؛ Smart Light خاموش. |
| **چیزی ردیابی نمی‌شود** (خط سبز نمی‌آید، شمارنده صفر) | ناحیه دید اشتباه، دوربین مایل، کارتن‌ها خارج از کادر | ناحیه دید را فقط روی صفحه کارتن‌ها بکشید؛ دوربین را روبه‌روی کارتن تنظیم کنید؛ نقطه سبز گوشه تصویر هنگام حرکت نقاله باید روشن شود. |
| **یک کارتن دو بار شمرده می‌شود** | دو دوربین روبه‌روی هم نیستند | دوربین‌ها را دقیقاً روبه‌روی هم در یک نقطه نقاله نصب کنید. |
| **کارتن‌های زیادی به بررسی دستی می‌روند** | حروف مهر کوچک، مهر کم‌رنگ، نور/تاری | بررسی «ارتفاع حروف مهر» (≥۳۰ پیکسل)؛ استامپ را پرجوهرتر کنید؛ نور و تاری را بهبود دهید؛ مطمئن شوید همه مهرهای فعال در شیفت/حالت آزمایش ثبت شده‌اند. |
| **مهر درست شناخته نمی‌شود چون در فهرست نیست** | مهر در شیفت ثبت نشده | در صفحه شیفت مهر را به کارگر تخصیص دهید. |
| **ضبط شروع نمی‌شود** | فضای دیسک کم | حداقل ۵ گیگابایت فضای خالی لازم است. |
| **برنامه بسته شد یا اجرا نمی‌شود** | — | دوباره `Behsard.exe` را اجرا کنید (داده‌ها حفظ شده‌اند)؛ فایل `data\logs\behsard.log` را بفرستید. |
